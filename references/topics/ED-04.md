# ED-04 — Shader and material extension points

When: A visual effect exceeds native material or animation settings.

Native candidates: `Shader`, `ShaderMaterial`, `VisualShader`.

## Approach

Consider the appropriate shader/material workflow for a graphics effect, checking the shader domain and renderer support.

CPU-side pixel/object updates or a custom rendering layer for work a suitable material/shader can express.

## Pitfalls

- 2D and 3D shader domains have different built-ins.
- Shader execution and state differ from ordinary GDScript.
- Renderer/platform support and visual/performance verification remain project-specific.

## Verify

- Preview and run the actual effect on the intended renderer.
- Verify shared material state and representative performance when affected.

## Version and limits

Godot 4.7 documentation; no runtime validation.

Specialist/target behavior needs project-specific research and calibration; also read [coverage boundaries](../discovery.md).
