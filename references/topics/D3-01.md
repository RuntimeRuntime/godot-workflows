# D3-01 — Imported 3D scenes and reimport-safe composition

When: External 3D asset carries hierarchy, animation, skin, or multiple authored objects.

Native candidates: `PackedScene`, `Node3D`, `AnimationPlayer`, `AnimationLibrary`.

## Approach

Import through the 3D scene importer and tune Import/Advanced Import Settings; put gameplay children and local overrides in an inherited or wrapper scene; choose scene or animation-library import by asset role.

Do not hand-recreate imported hierarchy or treat generated import output as the source of truth.

## Pitfalls

- Reimport replaces imported content.
- Editing source data after import may be preferable where applicable.
- Importer-generated child names can be brittle gameplay contracts.

## Verify

- Inspect imported node and animation lists.
- Add a local child/override, reimport, then reopen and confirm composition.
- Run one imported animation.

## Version and limits

Godot 4.7 import UI/options; confirm actual format importer and project version.
