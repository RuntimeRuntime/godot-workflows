# D2-02 — Tile terrains, alternatives and per-tile properties

When: Need automatic terrain edges/corners, rotated or varied tile variants, tile-specific collision/navigation/occlusion, or authored gameplay metadata.

Native candidates: `TileSet`, `TileSetAtlasSource`, `TileData`, `TileMapLayer`, `TileMapPattern`.

## Approach

Configure terrain sets and peering bits on atlas tiles, then paint with Connect or Path mode and use tile-specific overrides for exceptional joins. Author physics, navigation and occlusion polygons in TileSet layers. Use custom data layers for stable per-tile facts (for example damage or destructibility); use alternative tiles when a placed variant needs different tile metadata.

Avoid hand-coded edge/corner tile selection and parallel coordinate-to-metadata tables for static tile properties when TileSet terrains, alternatives and custom data fit. Keep runtime state such as a destroyed tile's changing health in owned game state rather than mutating shared tile definitions without an explicit design.

## Pitfalls

- Connect mode resolves neighbors on the same TileMapLayer; Path mode respects the current brush stroke and is useful for adjacent but separate roads.
- Custom data is defined by the TileSet tile and shared by every placement of that tile; a per-placement difference needs a distinct alternative or separate runtime state.
- Terrain peering bits and terrain IDs are distinct editor concepts; incomplete bits can yield unexpected transition tiles.
- TileMap built-in navigation has practical quality/performance limits; navigation polygons cannot be stacked on the same 2D navigation map.

## Verify

- Paint inside, edge, corner, empty-neighbor, crossing and adjacent-terrain cases; save/reopen and confirm selected variants.
- Read custom data in the actual gameplay path and verify collision/occlusion against the authored tile.
- If using navigation, inspect debug meshes and walk a path around corners and collision margins.

## Version and limits

Godot 4 terrain sets replace the distinct autotile workflow from Godot 3. Confirm editor affordances on the declared engine pin.
