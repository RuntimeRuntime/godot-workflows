# D3-04 — MultiMesh for dense repeated geometry

When: Many nearby copies of one mesh are needed, such as foliage or repeated props.

Native candidates: `MultiMeshInstance3D`, `MultiMesh`, `MeshInstance3D`.

## Approach

Store repeated mesh transforms in MultiMesh; optionally populate a target mesh surface from a source mesh through the editor workflow.

Do not create large numbers of identical ordinary scene nodes solely to render a static repeated set before considering MultiMesh.

## Pitfalls

- Instances are not individual gameplay nodes.
- It fits repeated copies of a mesh, not arbitrary per-instance scene behavior.
- Occluder baking does not include MultiMesh geometry automatically.

## Verify

- Check count, transforms, bounds and material.
- Profile a representative camera view on the target renderer/device.

## Version and limits

4.7 supports editor MultiMesh authoring; profile before selecting as an optimization.
