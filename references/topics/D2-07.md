# D2-07 — 2D cutout rigs and skeletal deformation

When: Animate a character built from articulated body pieces or deform a textured polygon around a 2D bone rig.

Native candidates: `Node2D`, `Sprite2D`, `RemoteTransform2D`, `Skeleton2D`, `Bone2D`, `Polygon2D`, `AnimationPlayer`, `AnimationTree`.

## Approach

For rigid cutout parts, structure the scene hierarchy around pivots and use AnimationPlayer; RemoteTransform2D or draw-order properties can separate transform parenting from render order. For deforming artwork, use Skeleton2D/Bone2D with Polygon2D UVs and weights, store a rest pose, and animate bones.

Use Godot's built-in cutout and skeleton workflow where its 2D art/rig requirements fit before writing a custom skeletal deformation layer. Frame animation remains appropriate for hand-drawn/cel animation and can complement cutout rigs.

## Pitfalls

- Both 4.7 tutorials are marked Work in progress and possibly outdated; validate exact steps in the actual editor/version.
- The cutout guide says IK chains work in the editor only, not at runtime; do not treat that editor authoring feature as runtime procedural IK.
- Correct scene parentage and visual draw order are separate concerns; 2D children draw in front of parents by default.
- Polygon triangulation and insufficient internal vertices/weights can cause unexpected bends; adding vertices requires assigning weights.

## Verify

- Reopen the rig and inspect bone hierarchy, pivots, rest pose, polygon weights and draw order.
- Preview key poses in the editor, then run clips in the actual game and inspect deformation, part ordering and collision alignment.
- If relying on IK or a specialized imported rig, verify the exact behavior on the declared Godot pin before encoding it as standard.
