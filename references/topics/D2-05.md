# D2-05 — Sprite sheets and frame-based animation

When: Animate a 2D character/object from separate frame images or a sprite sheet.

Native candidates: `Sprite2D`, `AnimatedSprite2D`, `SpriteFrames`, `AnimationPlayer`, `Texture2D`.

## Approach

Use AnimatedSprite2D with a SpriteFrames Resource for named frame animations and editor-managed frame order/speed/looping; its editor can slice a sheet. For a simple regular sheet, Sprite2D Hframes/Vframes and Frame can be animated by AnimationPlayer. Choose by the required authored control, not habit.

Do not create a custom frame timer, atlas parser or animation player for ordinary sprite-sheet playback; use SpriteFrames or AnimationPlayer's property tracks.

## Pitfalls

- Set the horizontal/vertical frame counts to the actual sheet grid and explicitly select the intended frames; an incorrect grid silently slices the wrong artwork.
- Check frame order, FPS, loop setting and the intended idle/one-shot completion behavior.
- AnimationPlayer changes are applied on its processing step, so a separately changed sprite property can briefly disagree for one frame.
- Starting a completed one-shot again from a per-frame loop can rewind a pose even when a completion signal fires only once. Give the start, completion and recovery transition an explicit owner.

## Verify

- Preview each SpriteFrames animation in the editor, then run the actor and check transitions, looping, facing and attack/death completion.
- Save/reopen and confirm the SpriteFrames resource and frame order persist.
- Test at project display scale for cropping, filtering and pivot/alignment issues.
- When replay or strike timing matters, record ordered frame/state changes through completion and recovery, not just a completion count. For example, intended `0,1,2` must reject an unrequested `0,1,2,0` rewind; explicit combos, cancellations and loops retain their own contract. Include affected hit/death interruptions and restart. Label each sample with its animation/state so recovery to idle frame 0 is not mistaken for attack replay.

## Version and limits

The 4.7 sprite animation tutorial covers both individual images and sheet workflows. Do not confuse AnimatedSprite3D or 3D imported animation requirements with this 2D branch.
