# D3-06 — Ray, shape, and direct-space queries

When: Gameplay needs sensing, picking, ground probing, line of sight, or swept-volume detection.

Native candidates: `RayCast3D`, `ShapeCast3D`, `PhysicsDirectSpaceState3D`, `PhysicsRayQueryParameters3D`, `PhysicsShapeQueryParameters3D`.

## Approach

Use RayCast3D for a persistent line query, ShapeCast3D for a swept volume, or direct space state for scripted one-off queries; set masks and exclusions to match intent.

Use the physics query API before building a custom general-purpose spatial query layer.

## Pitfalls

- Ray and volume casts answer different questions.
- A raycast may need an explicit update after same-tick parameter changes.
- Backend query details can differ.

## Verify

- Check origin/direction/shape and collision mask.
- Test a hit and miss plus exclusion/nearby geometry cases.

## Version and limits

4.7 query APIs; inspect selected physics backend and engine pin.
