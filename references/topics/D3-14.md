# D3-14 — GPU and CPU particle effects

When: An authored visual effect needs many transient particles, emitter shapes, turbulence, collision, trails, or sub-emitters.

Native candidates: `GPUParticles3D`, `CPUParticles3D`, `ParticleProcessMaterial`, `ShaderMaterial`, `GPUParticlesCollision3D`, `GPUParticlesAttractor3D`.

## Approach

Choose GPU particles for high counts/custom particle shaders and supported hardware; CPU particles for broader compatibility with simpler/count-limited effects; configure emitter/process material/draw pass and optional collision/attractors.

Use native particle features for visual effects before scripting individual transient nodes.

## Pitfalls

- GPU feature support is device/renderer dependent.
- Particles are not individually addressable gameplay actors.
- Occluder bake does not include particle geometry automatically.

## Verify

- Check visibility bounds, emission/restart and draw pass.
- Test on target device; verify collision or attractors when used.

## Version and limits

4.7 particle node set; select based on the actual renderer/device feature baseline.
