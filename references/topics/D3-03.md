# D3-03 — GridMap and MeshLibrary for 3D tile-based levels

When: Level pieces align to fixed-size cells and are drawn from a modular mesh set.

Native candidates: `GridMap`, `MeshLibrary`, `MeshInstance3D`, `StaticBody3D`, `CollisionShape3D`, `NavigationRegion3D`, `NavigationMesh`.

## Approach

Build/export MeshLibrary items from a Node3D-rooted source scene; each item uses a MeshInstance3D with optional static collision and navigation; paint cells with GridMap.

Prefer GridMap for supported mesh-cell authoring over a custom editor when its constraints fit.

## Pitfalls

- GridMap is not a generic node placement system.
- MeshLibrary export reads mesh material slots, not node overrides.
- Cell size, navigation cell size and baked resource timing matter.

## Verify

- Inspect cell size and representative placement.
- Test cell collision, navigation and material.
- Save/reopen and inspect library/map.

## Version and limits

Godot 4.7 GridMap flow; verify library constraints against target version.
