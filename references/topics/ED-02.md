# ED-02 — Custom import and export pipeline hooks

When: An unsupported source format or target-specific resource transformation needs pipeline integration.

Native candidates: `EditorImportPlugin`, `EditorExportPlugin`, `EditorPlugin`.

## Approach

Use native importer/exporter extension points when ordinary import settings and presets cannot meet the requirement.

Runtime parsers or post-export mutation scripts replacing a repeatable native content pipeline without a reason.

## Pitfalls

- Imported output is generated cache, not authoritative source.
- Import tutorial is marked WIP for 4.7; class docs need separate checking.
- An export hook can change packaged scenes/resources; editor success is insufficient.

## Verify

- Cold import from retained sources/settings.
- Reimport after changing source and confirm intended output.
- Inspect and launch the exact export with required content and tooling exclusion.

## Version and limits

4.7 importer tutorial explicitly marked possibly outdated; importer/exporter class descriptions inspected, no plugin executed.

Specialist/target behavior needs project-specific research and calibration; also read [coverage boundaries](../discovery.md).
