# D2-14 — 2D pathfinding: grid A* or navigation mesh

When: Implement NPC routes, tile-grid movement, continuous-area pathfinding, avoidance, navigation links or obstacles.

Native candidates: `AStar2D`, `AStarGrid2D`, `NavigationServer2D`, `NavigationRegion2D`, `NavigationPolygon`, `NavigationAgent2D`, `NavigationObstacle2D`, `NavigationLink2D`, `CharacterBody2D`.

## Approach

Choose AStarGrid2D for a partial cell grid with discrete positions and custom cell costs/solids; choose NavigationRegion2D/NavigationAgent2D when actors need paths through continuous walkable polygons, with NavigationServer2D providing the underlying query/map. The agent supplies path queries/avoidance helpers; the game still owns actor movement. Links describe a route connection, while code supplies traversal such as jump, ladder or teleport.

Do not hand-roll A* graph adjacency or continuous polygon navigation when AStarGrid2D or Godot's navigation mesh APIs fit. Keep custom path search for distinct graph costs/movement semantics that native options do not represent.

## Pitfalls

- AStarGrid2D is grid-based; NavigationServer2D is mesh-based. Choose from the movement space, not from a desire to use one universal AI node.
- NavigationAgent2D does not move the body for you; consume path positions and implement collision-aware movement.
- NavigationObstacle2D affects avoidance velocity, not pathfinding topology; update navigation meshes to change reachable areas.
- TileMap navigation can have pathfinding/path-following limitations; baked navigation regions may be preferable. Avoid overlapping/stacking 2D navigation meshes on the same map.

## Verify

- Inspect baked navigation debug meshes and margin from collision edges.
- Test reachable/unreachable targets, narrow passages, map sync after scene load, dynamic topology changes and actor collision response.
- For grid navigation, test diagonal policy, blocked cells and weighted paths; for mesh navigation, test agent avoidance separately from path choice.
- Exercise each link traversal in gameplay; a NavigationLink does not animate or teleport the actor by itself.

## Version and limits

Godot 4.7 uses AStarGrid2D and NavigationServer2D. Navigation agents/avoidance behavior can change across engine versions; calibrate path following and physics sync on the project's pin.
